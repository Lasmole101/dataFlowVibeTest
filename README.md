# dataFlowVibeTest

This is a project I created based on a colleague complaining the lack of freely available software design tools. Specifically data flow diagram makers.

I had been looking for an something to build as a test of vibecoding. Given the amount of time I spent on spec writing, clarification and context management I'm not sure if this fully count as just _vibes_. Although I did not handwrite a single line (other than the project name). It was fully generated using claude code. The first 8 phases (see docs/ implementation plan) by the free desktop app and then the next 2 via the pro subscripticlaude code cli. 

Either way it is a far cry from my usual "old skool" line by line embedded development and I thought I would publish it for anyone to come and laugh at the code quality.

Compiles and runs on ubuntu 24.04 wsl2 as of 29/05/26 and at least mostly works.
